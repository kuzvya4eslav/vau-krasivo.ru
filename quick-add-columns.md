# ⚡ Быстрое добавление столбцов "Показания", "Результат" и "Преимущества"

## 🎯 Что нужно сделать:

### **1. В Google Таблице:**
1. **Откройте** вашу таблицу с услугами
2. **Найдите** столбец "contraindications"
3. **Щелкните правой кнопкой** на столбце "contraindications"
4. **Выберите** "Вставить 1 справа" (3 раза)
5. **Назовите** новые столбцы:
   - `indications` - Показания
   - `result` - Результат
   - `advantages` - Преимущества

### **2. Структура таблицы теперь:**
| name | description | price | duration | category | detailed_description | preparation | aftercare | contraindications | **indications** | **result** | **advantages** | id |

### **3. Примеры заполнения:**

#### **Долговременная укладка бровей:**
- **indications:** `Для всех типов бровей, особенно для непослушных и редких волосков`
- **result:** `Идеальная форма бровей, которая держится 6-8 недель. Брови выглядят ухоженными и аккуратными без ежедневного ухода`
- **advantages:** `Экономия времени на ежедневном уходе, долговременный результат, естественный вид, подходит для всех типов бровей`

#### **Перманентный макияж бровей:**
- **indications:** `Для тех, кто хочет идеальную форму бровей на 1-3 года без ежедневного макияжа`
- **result:** `Идеальная форма бровей на 1-3 года. Естественный вид без ежедневного макияжа. Брови выглядят густыми и выразительными`
- **advantages:** `Долговременный результат, экономия времени, идеальная форма, естественный вид, подходит для активного образа жизни`

#### **Ламинирование ресниц:**
- **indications:** `Для всех типов ресниц, особенно для прямых и редких ресниц`
- **result:** `Объемные, изогнутые ресницы на 6-8 недель. Эффект завивки без туши и щипцов`
- **advantages:** `Долговременный результат, естественный вид, экономия времени на макияже, подходит для всех типов ресниц`

#### **№1 Ламинирование ресниц + оформление бровей:**
- **indications:** `Для тех, кто хочет обновить образ за один визит`
- **result:** `Идеальный образ с объемными ресницами и аккуратными бровями. Экономия времени и средств`
- **advantages:** `Скидка 300₽ по сравнению с отдельными процедурами, экономия времени, комплексный подход`

### **4. Проверка:**
1. **Сохраните** таблицу
2. **Обновите** сайт (F5)
3. **Откройте** любую услугу → "Узнать больше"
4. **Проверьте**, что появились новые разделы:
   - Показания ✨
   - Результат ✨
   - Преимущества ✨
