## 🎯 Как это работает:

### **1. В Google Таблице:**
- Каждая услуга имеет уникальный ID
- ID связывает данные с кнопками на сайте

### **2. На сайте:**
- Кнопки "Узнать больше" имеют `onclick="openModal('ID')"`
- JavaScript находит данные по ID
- Открывает правильное модальное окно

### **3. Пример работы:**
```html
<!-- Кнопка на сайте -->
<button onclick="openModal('brow-lamination')">Узнать больше →</button>

<!-- JavaScript находит данные -->
const procedure = procedures['brow-lamination'];
```

## 🔧 Если нужно изменить ID:

- Найдите услугу в таблице

### **Шаг 2: Обновите на сайте (если нужно)**
- Найдите кнопку "Узнать больше" для этой услуги
- Измените `onclick="openModal('старый-id')"` на `onclick="openModal('новый-id')"`

### **Шаг 3: Проверьте работу**
- Обновите страницу (F5)
- Нажмите "Узнать больше"
- Проверьте, что открывается правильное модальное окно
