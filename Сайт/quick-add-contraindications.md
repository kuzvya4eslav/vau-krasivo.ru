# ⚡ Быстрое добавление столбца "Противопоказания"

## 🎯 Что нужно сделать:

### **1. В Google Таблице:**
1. **Откройте** вашу таблицу с услугами
2. **Найдите** столбец "id" (последний столбец)
3. **Щелкните правой кнопкой** на столбце "id"
4. **Выберите** "Вставить 1 слева"
5. **Назовите** новый столбец: `contraindications`
6. **Заполните** данные для всех услуг

### **2. Структура таблицы теперь:**
| name | description | price | duration | category | detailed_description | preparation | aftercare | **contraindications** | id |

### **3. Примеры противопоказаний:**

**Для бровей:**
```
Аллергия на компоненты состава, воспаления в области бровей, беременность (первый триместр), кормление грудью, онкологические заболевания
```

**Для перманентного макияжа:**
```
Беременность, кормление грудью, онкологические заболевания, сахарный диабет, заболевания крови, аллергия на пигменты, воспаления в области бровей
```

**Для ресниц:**
```
Аллергия на компоненты состава, воспаления глаз, беременность (первый триместр), кормление грудью, онкологические заболевания
```

**Для комплексов:**
```
Аллергия на компоненты составов, воспаления в области глаз и бровей, беременность (первый триместр), кормление грудью, онкологические заболевания
```

### **4. Проверка:**
1. **Сохраните** таблицу
2. **Обновите** сайт (F5)
3. **Откройте** любую услугу → "Узнать больше"
4. **Проверьте**, что появился раздел "Противопоказания"
