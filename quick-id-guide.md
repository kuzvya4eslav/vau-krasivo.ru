# ⚡ Быстрое заполнение столбца ID

### **1. В Google Таблице:**
- Найдите столбец **`id`** (последний столбец)
- Заполните ID для каждой услуги

### **2. ID для всех 18 услуг:**

#### **Брови:**

### **3. Правила для ID:**
- ✅ Используйте **латинские буквы** и **дефисы**
- ✅ **Без пробелов** и **специальных символов**
- ✅ **Строчные буквы**
- ✅ **Уникальные** для каждой услуги

### **4. Проверка:**
1. **Сохраните** таблицу
2. **Обновите** сайт (F5)
3. **Нажмите** "Узнать больше" на любой услуге
4. **Проверьте**, что открывается правильное модальное окно
